# Weekly AI Review

ChatGPTでの週間活動を、家族にも共有しやすい形でまとめる Weekly Quest Dashboard です。

## GitHub Pages 公開準備

- 公開ファイル: `index.html`
- ブランチ: `main`
- 配置場所: リポジトリ直下 `/`
- `.nojekyll` 追加済み

## 想定公開URL

`https://layetylor-efc.github.io/weekly_ai_review/`

## Pages設定

GitHub の `Settings → Pages` で、Source を **Deploy from a branch** にし、Branch を **main / root** に設定してください。

> 現在リポジトリが private のため、公開要件はGitHubプラン/Pages設定に依存します。一般公開したい場合は、通常はリポジトリを public にしてからPagesを有効化するのが確実です。
